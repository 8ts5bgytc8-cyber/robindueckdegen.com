This is a simple test post documenting my first foray into the land of financial mathematics. I originally had the idea that I might be able to learn how to manage my own investments by learning about finance, but it's also convenient that a class (Math 336) required me to gather some data which was related to complex systems. I will first explain some of what I've been learning about stochastic processes, and some analysis techniques I would like to apply to the data, then I will explain how I actually collected the data, give some graphs, and finally a very basic analysis of the data. 

## Mathematical typesetting

Inline mathematics should render naturally inside prose, for example $A = U\Sigma V^*$.

Displayed mathematics should have enough room to read comfortably:

$$
T(x) = \sum_{n=0}^{\infty} a_n x^n.
$$
