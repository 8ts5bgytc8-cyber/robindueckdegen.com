## Mathematical typesetting

Inline mathematics should render naturally inside prose, for example $A = U\Sigma V^*$.

Displayed mathematics should have enough room to read comfortably:

$$
T(x) = \sum_{n=0}^{\infty} a_n x^n.
$$

## What a real note might contain

A project note can document a small experiment, a calculation, an implementation decision, or a concrete stage of a larger project. It does not need to be large enough to justify a separate project page.

The finished format should make it easy to move between a project overview and the individual notes that record its development.
